# STEPPE — 길이 이끄는 대로 (v1.3)

몽골에서 영감을 받은 가상의 무한 오픈 로드를 **오토바이** 또는 **탐험 왜건 자동차**로 자유롭게 달리는 1인용 웹 드라이빙·라이딩 게임입니다. PC(Chrome·Edge·Safari)와 모바일 화면·터치 조작을 지원합니다. 실제 위성 지형(DEM) 데이터는 사용하지 않았으며, 결정론적 절차 생성으로 끝없이 이어집니다.

## v1.3 주요 업데이트 (최상 그래픽 · 다중 노면 · 바이옴 · 모델 고도화)

1. **그래픽 품질 4단계 (`낮음` · `중간` · `높음` · `최상`) 및 PC `최상` 기본 적용**
   - 지원되는 PC에서는 **최상(Ultra)** 품질이 기본으로 선택됩니다(가시거리 전방 15청크 약 3.6km, 청크당 풀 인스턴스 14,500개, 픽셀 비율 상한 2.25, 4096 소프트 그림자, 16x 이방성 필터링, HDR 환경 반사).
   - 지형 멀티스케일 블렌딩 셰이더로 타일링 반복 무늬를 억제하고 자연스러운 초원·사막 색조를 표현했습니다.
2. **4종 PBR 도로 노면과 주행 감각·타이어 마찰음 연동**
   - `포장도로`(`asphalt_04`), `갈라진 도로`(`asphalt_02`), `비포장 자갈길`(`gravel_road`), `비포장 흙길`(`dirt_floor`) 및 길어깨(`sandy_gravel_02`)에 각각 고해상도 CC0 색상·노멀맵을 적용했습니다.
   - 노면에 따라 접지력(마찰 계수), 구름 저항, 차체 미세 진동, 타이어 자갈/흙 마찰 합성음이 달라지며 계기판에 현재 노면 이름이 표시됩니다.
3. **몽골 3대 바이옴(초원 → 호숫가 → 고비 사막) 자연 전이**
   - 주행 거리에 따라 **몽골의 초원**(`steppe`) → **초원 호숫가**(`lake`, 수면 물리 반사 및 완만한 호수 분지) → **고비 모래·자갈 지대**(`gobi`, 사구 지형과 사막 색조)가 끊김 없이 이어집니다.
4. **3D 차량·가축·몽골 풍경 디테일 대폭 보강**
   - **몽골 국기**: 2:1 비율, 좌측 소욤보(불·해·달·삼각형·수평 막대·태극 어문·기둥) 문양을 정확히 포함한 SVG 텍스처와 바람에 펄럭이는 천 정점 애니메이션을 적용했습니다(출발 지점 약 32m 앞 우측 및 720m 간격).
   - **염소(`createGoat`)**: 뒤로 휘어진 두 뿔, 귀, 턱수염, 목 털, 네 다리와 어두운 갈라진 발굽, 꼬리를 갖춘 모델로 고개를 숙여 풀을 뜯고 두리번거리는 움직임을 추가했습니다.
   - **추가 가축·풍경**: 양 무리, 갈기·꼬리가 있는 **몽골 말**, 고비 구간의 **쌍봉낙타**, 푸른 하닥(Khadag) 천이 감긴 **오보(Ovoo)**, 키릴 문자 거리 표지판(`УЛААНБААТАР` / `ДАЛАНЗАДГАД` / `ХАРХОРИН`), 천창(토오노)·굴뚝·태양광 패널·물통을 갖춘 **게르**, 만년설 능선 산맥.
   - **차량 디테일**: 오토바이(스포크 림, 브레이크 디스크/캘리퍼, 체인·스프라켓, 계기판, 라이더 바이저·부츠) 및 탐험 왜건 자동차(휠 아치, 그릴, 루프랙 제리캔·스페어타이어·사다리, 대시보드 내비게이션·송풍구·페달, 가감속 서스펜션 피치).

## 바로 실행 (로컬 실행법)

Node.js 20 이상이 설치된 환경에서 프로젝트 폴더를 열고 실행합니다. 별도 패키지 설치(`npm install`)나 빌드 과정이 필요 없습니다.

```powershell
npm.cmd start
```

출력된 `http://localhost:5173`에 브라우저로 접속합니다. 다른 포트를 쓰려면 다음과 같이 실행합니다.

```powershell
$env:PORT = '8439'
npm.cmd start
```

- HTML 파일을 탐색기에서 더블클릭하는 `file://` 방식은 브라우저의 ES 모듈 보안 정책(CORS) 때문에 실행되지 않으므로 반드시 로컬 정적 서버를 통해 접속하세요.
- Python이 설치되어 있다면 `python -m http.server 8439 --directory dist`로도 바로 실행할 수 있습니다.

## 조작 방법

| 기능 | PC (키보드 · 마우스) | 모바일 (터치 화면) |
|---|---|---|
| 가속 | `W` 또는 `↑` | 우측 하단 `가속 ↑` 버튼 홀드 |
| 제동 / 후진 정지 | `S`, `↓`, 또는 `Space` | 우측 하단 `제동` 버튼 홀드 |
| 좌우 조향 | `A`·`D` / `←`·`→` / 화면 마우스 드래그 | 좌측 하단 `‹` · `›` 버튼 홀드 |
| 크루즈 컨트롤 | 하단 `40` · `60` · `80` · `100` km/h 클릭 | 동일 |
| 크루즈 해제 | 제동(`S`/`Space`) 또는 `수동` 버튼 클릭 | 제동 버튼 또는 `수동` 터치 |
| 차량 변경 | `V` 키 또는 우측 상단 `차량` 메뉴 | 우측 상단 `차량` 메뉴 |
| 카메라 시점 전환 | `C` 키 또는 우측 상단 `시점` 메뉴 | 우측 상단 `시점` 메뉴 |
| 일시정지 / 설정 | `P` 또는 `Esc` / 우측 상단 버튼 | 우측 상단 정지 · 설정 버튼 |

- **주행 모드**: 관광 모드(최고 100km/h), 스피드 모드(최고 180km/h).
- **차로 유지 보조**: 설정에서 켜고 끌 수 있는 별도 옵션입니다(기본 켜짐). 직접 조향할 때는 수동 입력이 우선합니다.
- **차량 전환 규칙**: 주행 중 차량을 바꾸면 정차 상태(속도 0, 우측 차로 정렬)로 안전하게 전환되며 **누적 이동 거리(km)는 그대로 유지**됩니다. 선택한 차량·시점·품질 설정은 브라우저(`localStorage`)에 자동 저장됩니다.
- **안전 복구**: 도로 밖으로 크게 이탈하거나 급격한 슬립이 발생해도 게임오버 없이 약 1초 뒤 부드럽게 우측 차로로 복구합니다.

## 정적 웹 배포 방법

백엔드 서버나 데이터베이스가 전혀 필요 없는 순수 정적 웹사이트이므로 `dist/` 폴더 내부 파일만 업로드하면 됩니다.

1. **기존 주소(`https://steppe-ride-mongolia.leesj050300.chatgpt.site/`) 업데이트**:
   - `.openai/hosting.json`의 기존 `project_id`(`appgprj_6ad637135eb08191ad0d22d1bcb19021`)와 `dist` 경로 설정을 그대로 유지했습니다. 함께 생성된 `steppe-v1.3.tar.gz` 또는 `dist/` 폴더를 해당 프로젝트에 게시하면 기존 주소가 즉시 v1.3으로 갱신됩니다.
2. **Cloudflare Pages / Netlify / Vercel**:
   - Build command는 비워 두고, Publish directory(Output directory)를 `dist`로 지정하거나 `dist/` 폴더를 드래그 앤 드롭해 즉시 무료 배포할 수 있습니다.
3. **GitHub Pages**:
   - 저장소 설정(Settings → Pages)에서 `dist` 내용을 브랜치 루트(또는 `/docs`)로 지정해 배포합니다. 모든 리소스 경로가 상대 경로(`./`)로 작성되어 있어 서브경로 배포에서도 그대로 동작합니다.
