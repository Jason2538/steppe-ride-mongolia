# STEPPE — 길이 이끄는 대로

몽골에서 영감을 받은 가상의 무한 초원 도로를 달리는 1인용 웹 오토바이 게임입니다. PC와 모바일 화면을 지원합니다. 실제 지형 데이터는 사용하지 않았습니다.

## 그래픽 업데이트 1.1

사진 기반 CC0 초지·아스팔트 색상/노멀 재질, 4K 하늘 사진과 HDR 반사, 산맥, 휘어진 풀잎과 바람 움직임을 추가했습니다. 오토바이에는 둥근 모서리·타이어 트레드·서스펜션 코일·짐 고정 장치·헬멧 디테일을 보강했습니다.

출발 위치 앞 약 32m, 오른쪽 길가에 몽골 국기와 염소 무리가 있습니다. 이후 약 720m 간격으로 다시 나타납니다. 국기의 천과 염소 고개가 움직입니다. 국기 문양·사진 재질의 출처와 사용 조건은 `dist/credits.html` 및 `dist/assets/SOURCES.md`에 기록했습니다. 해당 하늘 사진은 몽골 현장 사진이 아닙니다.

## 바로 실행

Node.js 20 이상이 설치된 환경에서 이 폴더를 터미널로 열고 실행합니다.

```powershell
npm start
```

출력된 `http://localhost:5173`에 접속합니다. 패키지 설치나 빌드가 필요 없습니다. 다른 앱이 5173 포트를 사용하면 다음처럼 변경합니다.

```powershell
$env:PORT = '8439'
npm start
```

HTML 파일을 더블클릭하는 `file://` 방식은 ES 모듈의 브라우저 보안 정책 때문에 사용할 수 없습니다. Node 대신 Python이 있다면 `python -m http.server 8439 --directory dist`로 실행할 수 있습니다.

같은 Wi-Fi의 휴대폰에서는 PC의 로컬 IP와 포트를 사용합니다. OS 방화벽이 접근을 막는 경우가 있습니다. 공개 배포 주소는 PC 실행이나 같은 Wi-Fi 없이 접속할 수 있습니다.

## 조작

| 기능 | PC | 모바일 |
|---|---|---|
| 가속 | W / ↑ | 가속 버튼 누르기 |
| 제동 | S / ↓ / Space | 제동 버튼 누르기 |
| 좌우 조향 | A·D / ←·→ / 화면 위 마우스 드래그 | ‹·› 버튼 누르기 |
| 크루즈 | 40·60·80·100 버튼 | 같은 버튼 |
| 크루즈 해제 | 제동 또는 수동 버튼 | 동일 |
| 카메라 | C / 카메라 버튼 | 카메라 버튼 |
| 일시정지 | P / 정지 버튼 | 정지 버튼 |
| 설정 | 설정 버튼 | 설정 버튼 |

표준 매핑 게임패드의 왼쪽 스틱, RT/A 가속, LT/B 제동도 입력 경로가 있습니다. 실물 게임패드 검증은 하지 않았습니다. 마우스와 키보드는 함께 사용할 수 있습니다. 터치는 포인터 캡처로 버튼을 벗어나거나 앱 전환 시 입력이 해제됩니다.

관광 모드 최대 100km/h, 스피드 모드 최대 180km/h입니다. 차로 유지 보조는 기본으로 켜져 있으며 직접 조향할 때는 수동 입력을 우선합니다. 크루즈는 속도 제어이고 차로 보조는 별도 옵션입니다. 제동 시 크루즈가 해제됩니다. 도로를 크게 이탈하거나 심하게 불안정해지면 약 1초 뒤 도로로 복구합니다.

## 폴더 구조

```text
steppe-ride/
  dist/                  ← 이 안의 파일 전체가 웹 배포 대상
    index.html           시작 화면·HUD·설정·터치 버튼
    style.css            PC·모바일 반응형 스타일
    game.js              입력·게임 루프·카메라·UI
    simulation.js        고정 시간 간격의 주행 계산·지형 함수
    world.js             청크·도로·초원·하늘·풍경
    scenery.js           산맥·풀잎·국기·염소 모델
    bike.js              오토바이와 라이더의 3D 모델
    audio.js             엔진·바람 합성음
    credits.html         사용 자료·라이선스·구현 범위
    favicon.svg
    vendor/              Three.js r180 + MIT 라이선스
    assets/              CC0 재질·하늘, 공개 도메인 국기, SOURCES.md
  tests/simulation.mjs    주행 계산 검증
  server.mjs             개발용 정적 서버
  package.json
  DESIGN-AND-RESEARCH.md  조사·기획·구조·확장 계획
  VALIDATION.md          검증 결과와 제한
  .openai/hosting.json    Sites 배포 설정
```

초기 기술 제안의 TypeScript/Vite 대신, 설치와 빌드가 필요 없는 표준 JavaScript ES 모듈로 구현했습니다. 사용자가 JavaScript 기초 지식으로 파일을 수정하고 정적 호스팅에 올리기 쉽게 하기 위한 선택입니다. 의존 라이브러리는 Three.js 하나이며 로컬 파일로 포함되어 있습니다.

## 검증 실행

```powershell
npm run check
```

JavaScript 문법과 가속·관성·크루즈·제동·최고 속도·1시간 주행·복구·조향/린·지형 연결을 검사합니다. 물리 계산 검사는 브라우저 렌더링이나 모든 기기의 성능을 보장하는 테스트가 아닙니다.

## 정적 웹 배포

게임을 위한 백엔드는 필요 없습니다. 개발 서버 `server.mjs`를 인터넷 서비스로 운영할 필요도 없습니다. `dist` 내용만 정적 호스팅에 배포하면 됩니다.

**Sites:** `.openai/hosting.json`에 등록된 프로젝트를 사용합니다. 이 폴더의 배포 설정은 `dist`를 가리킵니다. 사이트 변경 후에는 같은 프로젝트에 새 버전을 배포해야 합니다. 새 프로젝트를 다시 만들지 마세요.

**GitHub Pages 대안:** 저장소의 배포 대상 루트에 `dist` 안의 파일들을 넣고 저장소의 Pages 설정에서 해당 브랜치를 지정합니다. 원본의 상위 `index.html`을 찾는 방식이므로 폴더째 잘못 한 단계 감싸지 않도록 주의하세요. 상대 경로를 사용해 하위 경로 배포에도 대응합니다. 비용과 공개 저장소 여부는 호스팅의 현재 무료 플랜 조건을 확인하세요.

**Netlify/Cloudflare Pages 대안:** 정적 업로드 또는 저장소 배포 시 빌드 명령은 비우고 게시 디렉터리를 `dist`로 지정합니다. 별도 API 키, 유료 에셋, 데이터베이스가 필요 없습니다. 서비스별 무료 한도는 제공자 정책에 따릅니다.

## 구현 범위와 제한

- 지형은 몽골에서 영감을 받은 창작 코스이며 실제 GPS 경로/위성 높이를 재현하지 않습니다.
- 낮·초원·아스팔트 중심 MVP입니다. 초지로 벗어나면 저항·접지·진동이 달라집니다.
- 관성, RPM·자동 기어, 접지 한계와 복구는 간소화한 주행 모델입니다. 실제 오토바이의 정밀 시뮬레이션은 아닙니다.
- 4개 카메라는 뒤 따라가기·헬멧·핸들바·넓게 보기입니다. 4번째는 자유 조작 카메라가 아닙니다.
- 엔진·바람 볼륨을 독립 조절합니다. 배경음악과 음악 볼륨은 음악 추가 단계에서 구현합니다.
- Safari·실물 모바일·실물 게임패드에서의 검증은 별도 필요합니다. Chrome/Edge도 모든 GPU·모델에서 30fps를 보장하지 않습니다.
- 저장은 브라우저 설정만 localStorage에 기록합니다. 이어 달리기 진행 저장은 미구현입니다.
- 소리 시작은 브라우저 정책에 따라 출발 또는 소리 버튼 클릭이 필요합니다.

사용 자료는 `dist/credits.html`에 모두 기록되어 있습니다.
